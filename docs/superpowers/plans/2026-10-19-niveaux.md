# Niveaux (Doux / Tonique / Costaud) — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter trois niveaux d'effort, choisis par une pastille facultative au départ et ajustés par « L'effort ? Trop facile · Juste bien · Trop dur » sur Bravo, avec 20 exercices de niveau 2-3 et leurs poses.

**Architecture:** Le niveau est une donnée d'exercice (`niveau: 1 | 2 | 3`) et un paramètre de séance. Le générateur ne propose jamais un exercice au-dessus du niveau de la séance et, au cœur, préfère le niveau demandé (nouvelle clé de choix). Le niveau de l'utilisateur vit dans sa propre clé de stockage, lue à chaque affichage du départ et modifiée par la pastille ou par la réponse d'effort ; il voyage dans l'URL de séance et s'enregistre dans le journal (et dans Supabase).

**Tech Stack:** Expo SDK 58, Expo Router 58 (`mobile/app/`), React Native 0.88, TypeScript strict, Jest via jest-expo, RNTL 14 asynchrone, react-native-svg (figurine), Supabase (migration SQL).

**Spec:** `docs/superpowers/specs/2026-10-19-niveaux-design.md`

## Global Constraints

- Zéro configuration : niveau 1 « Doux » par défaut ; lancer reste un seul tap ; rien n'est demandé avant la première séance.
- Les contraintes de contexte ne sont jamais assouplies ; un exercice de niveau > N n'apparaît jamais dans une séance de niveau N (aucune phase, aucun palier d'assouplissement).
- Noms exacts : 1 « Doux », 2 « Tonique », 3 « Costaud » ; phrases de la feuille : « Doux : on bouge sans forcer », « Tonique : ça chauffe un peu », « Costaud : pour celles et ceux qui s'entraînent déjà ».
- Textes Bravo exacts : « L'effort ? » puis « Trop facile » · « Juste bien » · « Trop dur » ; après réponse, si le niveau change : « Prochaine séance : niveau <Nom> », sinon rien de plus que le « Merci ! » existant de la ligne d'effort (« Noté ! »).
- Pas de ligne d'effort quand rien n'a été fait (écran « À bientôt ! »).
- Clé de stockage du niveau : `flashcoach.niveau` (valeur JSON `1`, `2` ou `3` ; illisible ou invalide → 1). (Écart assumé avec la spec qui disait « clé de préférences existante » : une clé à part évite que l'écran de départ, monté pendant la séance, réécrive un niveau périmé.)
- Écran de départ : tient sans défilement à 375 × 812 avec « Lancer ma séance » visible ; cibles 48 dp ; design de `DESIGN.md` (noir sur orange, jamais de blanc sur orange).
- Journal : `niveau` (1-3) et `effort` (`'facile' | 'juste' | 'dur' | null`) ; anciennes entrées sans ces champs restent valides (niveau 1, effort null).
- Figurine : épaules intégrées au buste, aucune « boule » aux articulations (retour de Mattia).
- `npx jest`, `npm run typecheck`, `npm run lint` propres depuis `mobile/` ; `npm run couverture` reste « Catalogue complet » pour le niveau 1.
- Commits terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` ; jamais `.claude/`, `.superpowers/`, `.impeccable/`, `.env*.local`.

- [ ] **Step 1: Préférence de niveau (tests d'abord)**

`preferences/niveau.ts` — mêmes règles que `preferences.ts` (lecture et écriture n'échouent jamais) :

```ts
import { NIVEAUX, type Niveau } from '../catalogue/types';
import type { Effort } from '../journal/journal';
import type { Stockage } from './stockage';

export const CLE_NIVEAU = 'flashcoach.niveau';

export async function lireNiveau(stockage: Stockage): Promise<Niveau> {
  try {
    const texte = await stockage.lire(CLE_NIVEAU);
    const valeur: unknown = texte === null ? 1 : JSON.parse(texte);
    return NIVEAUX.includes(valeur as Niveau) ? (valeur as Niveau) : 1;
  } catch {
    return 1;
  }
}

export async function ecrireNiveau(stockage: Stockage, niveau: Niveau): Promise<void> {
  try {
    await stockage.ecrire(CLE_NIVEAU, JSON.stringify(niveau));
  } catch {
    // Niveau non enregistré : la prochaine séance repartira du niveau lu.
  }
}

// « Trop facile » monte d'un cran, « Trop dur » descend d'un cran, bornés à 1-3.
export async function ajusterNiveau(stockage: Stockage, effort: Effort): Promise<{ avant: Niveau; apres: Niveau }> {
  const avant = await lireNiveau(stockage);
  const pas = effort === 'facile' ? 1 : effort === 'dur' ? -1 : 0;
  const apres = Math.min(3, Math.max(1, avant + pas)) as Niveau;
  if (apres !== avant) await ecrireNiveau(stockage, apres);
  return { avant, apres };
}
```

Tests : défaut 1 ; valeur invalide (`"4"`, `"x"`, JSON abîmé) → 1 ; stockage en panne → 1 sans rejet ; `ajusterNiveau` monte, descend, borne à 3 et à 1, `juste` ne change rien et n'écrit pas.
