# Séances prêtes en circuit — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter 13 séances prêtes en circuit (5 postes de 30 s, 1 min 30 de repos entre les tours), jouées par le lecteur existant, accessibles depuis une icône de l'écran de départ, avec 6 nouveaux exercices et leurs poses.

**Architecture:** Les circuits sont des données (`src/circuits/`) transformées par une fonction pure en `Seance` (mêmes `Bloc` que la séance flash, avec deux champs facultatifs : `tour` et `cote`). L'écran Séance choisit la source (générateur ou circuit) selon l'URL ; tout le reste (lecteur, journal, Bravo) est réutilisé. Deux écrans s'ajoutent (liste, détail) ; le journal et Supabase apprennent `circuitId`.

**Tech Stack:** Expo SDK 58, Expo Router 58 (`mobile/app/`, route dynamique `circuit/[id].tsx`), React Native 0.88, TypeScript strict, Jest via jest-expo, RNTL 14 asynchrone, react-native-svg.

**Spec:** `docs/superpowers/specs/2026-10-22-circuits-design.md` (et son contenu : `docs/superpowers/specs/2026-10-22-circuits-proposition.md` v2).

## Global Constraints

- Le lancement en un tap de la séance flash ne change pas ; l'écran de départ ne gagne aucune ligne et tient sans défilement à 375 × 812 et 360 × 740 avec « Lancer ma séance » visible ; en-tête empilé (logo au-dessus, « Flash Coach » dessous) à toutes les hauteurs.
- Les 13 circuits sont **exactement** ceux de la proposition v2 §3 (ordre des postes, tours, côtés G/D) ; Doux = 3 tours, Tonique = 4, Costaud = 4 + 5e facultatif.
- Format exact : échauffement 4 × (5 s + 25 s) ; chaque poste 10 s de transition + 30 s d'effort ; premier poste des tours 2+ : 90 s de transition (repos) ; retour au calme 2 × (5 s + 25 s). Durées : 3 tours 960 s, 4 tours 1250 s, 5 tours 1540 s.
- Textes exacts : « Séances prêtes » ; « Conseil : 2 séances par semaine, jours non consécutifs. Garde 1 à 3 répétitions en réserve. » ; « Je n'ai pas de meuble stable » ; « Ajouter un 5e tour » ; « Utilise une chaise ou une table stable, ni pliante ni vitrée. » ; « C'est parti » ; en séance : « Échauffement », « Tour n / N », « Retour au calme », « Repos · À suivre : <exercice> », « Dernier tour ! Va au bout si la technique reste propre. »
- Aucune promesse de prise de masse ; les sources restent dans la spec (pas dans l'app pour l'instant).
- Le niveau 1 du rapport de couverture reste « Catalogue complet » ; les séances flash existantes ne changent pas (mêmes séances pour une graine donnée, sauf si un des 6 nouveaux exercices y entre : adapter les attentes à graine fixe, jamais les affaiblir).
- Design `DESIGN.md` (noir sur orange, cibles 48 dp, `TYPO`, `ELEVATION`) ; figurine aux épaules intégrées, sans « boules » aux articulations.
- `npx jest`, `npm run typecheck`, `npm run lint` propres depuis `mobile/`. Commits terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` ; jamais `.claude/`, `.superpowers/`, `.impeccable/`, `.env*.local`.

- [ ] **Step 4: Construction (tests d'abord)**

`construire.ts` :

```ts
import { EXERCICES } from '../catalogue/exercices';
import type { Exercice } from '../catalogue/types';
import type { Bloc, Seance } from '../generateur/types';
import type { Circuit } from './types';

const ECHAUFFEMENT = ['rotation-epaules', 'cercles-hanches', 'marche-sur-place', 'rotation-poignets'];
const RETOUR_AU_CALME = ['respiration-ventre', 'etirement-ciel'];
export const REPOS_ENTRE_TOURS_S = 90;
const TRANSITION_S = 10;
const EFFORT_S = 30;

function exercice(id: string): Exercice {
  const trouve = EXERCICES.find((e) => e.id === id);
  if (!trouve) throw new Error(`Exercice inconnu dans un circuit : ${id}`);
  return trouve;
}

export function nombreDeTours(circuit: Circuit, tourEnPlus: boolean): number {
  return circuit.tours + (tourEnPlus && circuit.tourFacultatif ? 1 : 0);
}

export function construireSeanceCircuit(
  circuit: Circuit,
  { sansMateriel, tourEnPlus, graine }: { sansMateriel: boolean; tourEnPlus: boolean; graine: number },
): Seance {
  const total = nombreDeTours(circuit, tourEnPlus);
  const blocs: Bloc[] = ECHAUFFEMENT.map((id) => ({ exercice: exercice(id), phase: 'mise_en_route', transitionS: 5, effortS: 25 }));
  for (let numero = 1; numero <= total; numero++) {
    circuit.postes.forEach((poste, index) => {
      const id = sansMateriel && poste.sansMateriel ? poste.sansMateriel : poste.exerciceId;
      blocs.push({
        exercice: exercice(id),
        phase: 'coeur',
        // Le repos entre deux tours est la transition du premier poste : on y voit l'exercice qui arrive.
        transitionS: index === 0 && numero > 1 ? REPOS_ENTRE_TOURS_S : TRANSITION_S,
        effortS: EFFORT_S,
        tour: { numero, total },
        ...(poste.cote ? { cote: poste.cote } : {}),
      });
    });
  }
  blocs.push(...RETOUR_AU_CALME.map((id) => ({ exercice: exercice(id), phase: 'retour_au_calme' as const, transitionS: 5, effortS: 25 })));
  const dureeTotaleS = blocs.reduce((somme, bloc) => somme + bloc.transitionS + bloc.effortS, 0);
  return {
    contexteId: 'maison',
    contraintes: { tenue: 'sport', bruit: 'normal', espace: 'un_peu', sol: true },
    ressenti: 'en_forme',
    duree: Math.round(dureeTotaleS / 60) as Seance['duree'],
    graine,
    blocs,
    dureeTotaleS,
    assouplissement: 0,
    niveau: circuit.niveau,
    circuitId: circuit.id,
  };
}
```

(Si `Seance.duree` est typé `Duree` (3 | 5 | 10), élargir le type de `Seance.duree` à `number` en gardant `ParametresSeance.duree: Duree` ; ajuster les usages typés sans changer le comportement de la séance flash.)

Tests : durées exactes 960 / 1250 / 1540 s (Doux, Tonique, Costaud + tour en plus) ; tour en plus ignoré hors Costaud ; 90 s exactement sur le premier poste des tours 2+ et nulle part ailleurs ; `tour` et `cote` posés ; substitutions sans meuble (et `cote` conservé pour bulgare → fentes) ; 4 blocs d'échauffement, 2 de retour au calme ; `circuitId` et `niveau` portés.
